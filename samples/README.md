# Samples

Examples of accessible publications and synchronized media.

## DAISY 2.02

- [Fire Safety](Firesafety-DAISY-202/), by Wendy Blaxland: an English book combining full text, WAV narration, images, and SMIL synchronization, with heading and page navigation. Start with [ncc.html](Firesafety-DAISY-202/ncc.html).

## EPUB 3 Media Overlays

Four test books from the Swedish Agency for Accessible Media (MTM), combining XHTML text, synthesized MP3 narration, and SMIL synchronization:

- [English markup tests](Sample%20files%20Media%20Overlays%20MTM/Sample-file_EN.epub): headings, page numbers, images, tables, lists, poetry, links, notes, and code.
- [Swedish markup tests](Sample%20files%20Media%20Overlays%20MTM/testbook_EPUB3_260821.epub): structural markup plus Swedish and English speech synthesis pronunciation tests.
- [Multilingual tests](Sample%20files%20Media%20Overlays%20MTM/testbook_EPUB3_260123_languages.epub): repeated markup examples in nine languages, including tables, image descriptions, sidebars, and footnotes.
- [Advanced Tests for Accessible Mathematics](Sample%20files%20Media%20Overlays%20MTM/Advanced_Tests_for_Accessible_Mathematics.epub): Celia's MathML Core tests, adapted by MTM with narration, covering inline and block mathematics, elements, and attributes.

## eBraille

Two editions of Goethe's *Kleinere Novellen*, using German grade 2, six-dot Unicode Braille, with navigation and Braille CSS:

- [Single rendition](eBraille/kleinere_novellen.ebrl) ([unpacked files](eBraille/kleinere_novellen/)): the Braille edition.
- [Multiple renditions](eBraille/kleinere_novellen-multi-rendition.ebrl) ([unpacked files](eBraille/kleinere_novellen-multi-rendition/)): Braille and original German text, connected through a rendition mapping using EPUB CFIs.
